🔐 Secure Enterprise RAG System

⚡ Stack: FastAPI + React 18 + FAISS + PyJWT
01. Problem Statement

The Enterprise AI Security Crisis

🚨

Prompt Injection Attacks

Malicious users can bypass system boundaries using jailbreaks ("Ignore previous instructions") to force LLMs into outputting restricted administrative commands.

🔓

Unfiltered Vector Access

Standard RAG systems retrieve documents based on semantic similarity alone, leaking confidential HR or executive financial documents to unauthorized lower-tier staff.

🛡️

PII & Data Leakage

Sending raw employee documents (containing Aadhaar, PAN numbers, and salary data) to public cloud LLM APIs violates compliance standards like GDPR & DPDP.

02. Our Solution

Zero Trust Defense-in-Depth Architecture

Our platform operates on the core principle: Never Trust The Input, Never Trust The LLM. Every single prompt and response is evaluated across multiple independent safety filters.

1

Pre-Retrieval Validation

Dual Injection Detection (Regex Patterns + ML Classifier) stops attacks before vector database retrieval occurs.

2

Role-Based Vector Metadata RBAC

FAISS search is pre-filtered by JWT user roles (Admin, HR, Employee, Intern), preventing unauthorized chunk retrieval.

3

PII Redaction Engine

Automated scrubbing of Aadhaar, PAN, Emails, and Phone Numbers before building the final prompt context.

4

Air-Gapped Local LLM & Response Guard

Local inference via Phi-3 / Ollama coupled with post-generation output sanitization and immutable JSON audit logging.
